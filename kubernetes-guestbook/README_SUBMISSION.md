# IBM Guestbook final project — 10 submission answers

This folder includes **working application source** and the exact commands to collect **real** IBM Cloud and Kubernetes terminal evidence. It DOES NOT contain fake deployment logs. Run the commands in the course IBM Skills Network lab session where `docker`, `ibmcloud`, `kubectl` and an authenticated Kubernetes cluster are available.

## Set up (in the lab terminal)
```sh
git clone https://github.com/lloor7021-afk/github-final-project.git
cd github-final-project/kubernetes-guestbook
export MY_NAMESPACE="$(ibmcloud cr namespaces -q | head -n 1)"
echo "$MY_NAMESPACE"
# If blank, set the course namespace manually: export MY_NAMESPACE=your-actual-namespace
```

**Do not continue until you see your real namespace.** If your course runs in a disposable lab, verify `ibmcloud login` and Kubernetes access with `kubectl get nodes`. In commands below, run in `kubernetes-guestbook` unless a `cd` is shown.

## Initial deployment and HPA for Questions 4 and 5
```sh
sed "s/REPLACE_WITH_YOUR_NAMESPACE/$MY_NAMESPACE/g" v1/guestbook/deployment.yml > deployment.yml
kubectl apply -f deployment.yml
kubectl apply -f service.yml
kubectl rollout status deployment/guestbook
kubectl autoscale deployment guestbook --cpu-percent=5 --min=1 --max=10
```
If the HPA already exists, use `kubectl get hpa guestbook`. **Kubernetes does not generally allow `minReplicas: 0` for ordinary CPU-based HPA.** The requested zero replica count reflects an observation, not a configuration you should invent.

## Question 5 — real autoscaling result
Generate safe short-lived load INSIDE the lab's Kubernetes cluster:
```sh
kubectl run guestbook-load --image=busybox:1.36 --restart=Never -- /bin/sh -c 'i=0; while [ "$i" -lt 5000 ]; do wget -q -O /dev/null http://guestbook:3000/ || true; i=$((i+1)); done'
kubectl get hpa guestbook --watch
```
When replicas rise, stop watching (Ctrl+C), then:
```sh
kubectl get hpa guestbook | tee evidence/hpa2
kubectl delete pod guestbook-load --ignore-not-found
```
Only paste the output if it ACTUALLY shows scaling. HPA needs working cluster metrics and may take minutes. The number of replicas may differ.
