# Simple Interest Calculator

This project provides a simple interest calculator written in Bash.

## Description

The script takes the principal amount, annual interest rate (percentage), and time period (years), then calculates simple interest.

**Formula:** Simple Interest = (Principal × Annual Rate × Time) / 100

## Inputs

- **p**: Principal amount
- **r**: Annual rate of interest (percent)
- **t**: Time period in years

## Output

- Calculated simple interest.

## Usage

Run the following command in a terminal with Bash installed:

```bash
bash simple-interest.sh
```

Example: principal = 1000, rate = 5, time = 2 years → simple interest = 100.
