# Express Book Review – IBM Node.js Final Project

This solution follows the `final_project/` starter structure from IBM's `ibm-developer-skills-network/expressBookReviews` repository. It implements public lookups by ISBN, author and title; user registration and login; authenticated review add/update/delete; and promise-based Axios client functions.

## Run and collect authentic terminal evidence

```bash
cd final_project
npm install
npm start
# Open a second terminal in the same folder:
bash scripts/collect-evidence.sh
```

The `final_project/evidence/` files generated by the script include the actual executed `curl` commands and responses from your running server. They are *not* included in the Git repository by default because the file contents may contain disposable test account names. The screenshots/rubric call these `getallbooks`, `getbooksbyISBN`, `getbooksbyauthor`, `getbooksbytitle`, `getbookreview`, `register`, `login`, `reviewadded`, `deletereview`. Paste each file into its matching question (questions 2–10).

## Rubric match

- **Task 1:** Fork the original IBM repository using GitHub's **Fork** button. A copy of source code in another repository is not a fork; the fork relation must be verified by the live GitHub API.
- **Tasks 2–6:** Public Express routes (`/`, `/isbn/:isbn`, `/author/:author`, `/title/:title`, `/review/:isbn`).
- **Tasks 7–8:** `POST /register`, `POST /customer/login` with session cookie and JWT.
- **Tasks 9–10:** `PUT /customer/auth/review/:isbn`, `DELETE /customer/auth/review/:isbn`.
- **Task 11:** GitHub URL of `final_project/router/general.js` which exports `getAllBooks`, `getBooksByISBN`, `getBooksByAuthor`, `getBooksByTitle` using Axios and async/await. Also supports a test script.

Data is stored in process memory for the class assignment, not a production database. Provide real, verifiable output; do not substitute example response text for test logs.
